# Hello World — Fake Classroom 50 Assignment

Implement `greet(name: str) -> str` in `main.py`.

## Requirements
- Return `Hello, <name>!`
- Preserve the name exactly (do not trim or change capitalization).
- An empty name returns `Hello, !`

## Run locally
```bash
python -m pytest -q
```

This is a teaching/demo assignment, not a real course assignment.
